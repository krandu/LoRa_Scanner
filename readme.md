# LoRa & Spectrum Analyzer — Heltec WiFi LoRa 32 V2

基于 **Heltec WiFi LoRa 32 V2** 的双模式无线电分析工具，集成了 **全频段频谱/瀑布图分析** 与 **LoRa/Meshtastic 数据包分析解码** 两个核心功能。

---

## 核心特性

- **双模式自由切换**：双击板载 PRG 按键呼出模式切换菜单，长按确认。
- **430–440 MHz 频谱与瀑布图模式（默认启动）**：
  - **动态全频段扫频**：自动划分 **40 个通道**（步长 250 kHz），单次全频扫描仅需 **~140 ms**，刷新率达 **~7 FPS**。
  - **柱状图 + 顶端峰值（Peak Hold）**：清晰展现实时信号分布及频点能量。
  - **三阶灰度点阵瀑布图**：利用 16 行历史滚动图和棋盘格抖动点阵区分强、中、弱信号。
  - **自动峰值追踪**：顶部状态栏实时显示当前频段内的最大 RSSI 及对应频率点（例如 `PK:438.13`）。
- **LoRa / Meshtastic 接收解码模式**：
  - **实时 RSSI 柱状波形图**：无信号锁定状态下显示平滑的 RSSI 时间序列。
  - **数据包解析与自动锁定**：接收到数据后自动锁定界面，直接提纯并解析 APRS / Meshtastic 文本消息或转 HEX 输出。

## 按键与菜单交互说明

系统采用状态机精确识别 **单击**、**双击** 与 **长按** 动作：

### 1. 全局快捷操作

| 动作 | 判定条件 | 触发功能 |
|---|---|---|
| **双击** | 两次间隔 $< 350\text{ ms}$ | **呼出 / 退出 模式选择菜单** |

---

### 2. 模式菜单内操作（Menu Display）

| 动作 | 功能 |
|---|---|
| **单击** | 切换菜单高亮选项（1. Spectrum Scanner $\leftrightarrow$ 2. LoRa Receiver） |
| **长按 ($\ge 1.2\text{s}$)** | **确认选择** 并切换至所选模式（菜单自动关闭） |

---

### 3. 各模式下的操作按键映射

* **频谱分析模式 (`MODE_SPECTRUM`)**：
  * **双击**：进入模式选择菜单。

* **LoRa 接收分析模式 (`MODE_LORA_ANALYZER`)**：
  * **锁定状态（`[LOCKED]`）**：**单击** 或 **长按** 均可解除锁定，恢复继续监听。
  * **未锁定状态**：
    * **单击**：切换不同的 **SF / CR 速率组合**（SF7~SF12）。
    * **长按 ($\ge 1.2\text{s}$)**：切换至预设频率列表（438.150, 438.125, 438.000, 438.500 MHz）中的下一个频点。

## 频谱模式计算逻辑与扫频参数

* **频段跨度 (Span)**：$440.0\text{ MHz} - 430.0\text{ MHz} = 10.0\text{ MHz}$
* **通道数量 (Channels)**：$40$ 个通道
* **通道步长 (Step/RBW)**：$\frac{10.0\text{ MHz}}{40} = 250\text{ kHz}$
* **扫频建立延时**：单频点切换后强制延时 $2.5\text{ ms}$ 以等待 RF 前端 RSSI 积分稳定。
* **刷新率与性能**：单次全频段扫描总耗时约为 $\approx 130\sim 140\text{ ms}$，可提供流畅的 **~7 FPS** 瀑布图图表更新速度。

## 常见问题 (FAQ)

**Q: 频谱模式下为何瀑布图有些点是密集的点阵，有些是全亮块？**  
A: 为了在单色 OLED (128x64) 上展示三阶信号强度，我们使用了棋盘格抖动算法（Dithering）：
- **弱信号 ($\le -95\text{ dBm}$)**：不显示（留黑）。
- **中等信号 ($-95\text{ dBm} \sim -75\text{ dBm}$)**：点阵交错半亮（抖动绘制）。
- **强信号 ($> -75\text{ dBm}$)**：完全点亮成实心块。

**Q: 上电启动后默认是哪个模式？**  
A: 默认自动进入 **频谱分析模式 (`MODE_SPECTRUM`)**，起始范围为 `430.000 MHz ~ 440.000 MHz`。需要分析特定 LoRa 解码包时，可双击 PRG 按键切入 LoRa 接收模式。
